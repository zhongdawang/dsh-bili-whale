# Changelog

## 0.2.0 — 2026-11-05

### 新增

- **人设**：`reply.persona`，控制台可直接编辑；会拼到 LLM 系统提示词前面，不覆盖 `systemPrompt`。
- **Token 用量**：记录每次 LLM 调用的 input / output / reasoning / total 到 `data/usage.json`，控制台实时显示今日用量、调用次数、最近耗时。
- **智能热场**：
  - 没人说话时按间隔自动发一句。
  - 支持安静时段、每小时/每天上限、连续没人接话长冷却、最低在线人数。
  - 话题库 + LLM 生成，LLM 失败自动退回话题库。
  - 控制台支持「预览一条」「立即热场」「发送预览的那条」。
  - 手动热场通过 IPC 发送给助手进程，不会和自动回复抢锁。
- **测试**：新增 token 用量、热场判定、人设注入、usage 累计等用例，总计 36 个。

### 调整

- LLM 调用返回 `{ text, usage, ... }`，回复和热场共用同一套 token 统计。
- 热场的 dry-run 不消耗每小时/每天额度。
- 日志里自己的回复回声只提示一次，不再重复打印内容。
- `config.example.json` 补充人设、热场、token 相关默认值。

## 0.1.0 — 2026-11-04
